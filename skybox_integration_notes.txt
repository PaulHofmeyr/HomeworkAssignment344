    #include "Skybox.h"

    GLuint skyboxShader = LoadShaders("skyboxVert.glsl", "skyboxFrag.glsl");

── 3. After PostProcess pp; pp.init(...); add: ──────────────────────────────

    Skybox skybox;

── 4. Inside the render loop, INSIDE pp.bindFBO() … pp.unbindFBO(),
      draw the skybox FIRST (before drawScene / drawRotor): ─────────────────

    // ── Draw skybox first (behind everything) ─────────────────────────────
    skybox.draw(skyboxShader, view, proj);

    The full order in that block should be:
        pp.bindFBO();
        glClear(GL_COLOR_BUFFER_BIT | GL_DEPTH_BUFFER_BIT);
        glUseProgram(app.sceneShaderID);
        ... (upload uniforms, view/proj, lighting, shadow maps) ...

        // Draw skybox before scene geometry
        skybox.draw(skyboxShader, view, proj);

        // Restore scene shader after skybox (skybox.draw changes the active program)
        glUseProgram(app.sceneShaderID);

        // Draw scene
        { float id[16]; ... }
        drawScene(app.wireframe);
        ...
        drawRotor(app.wireframe);
        pp.unbindFBO();

── 5. In the cleanup section before glfwTerminate(), add: ───────────────────

    skybox.cleanup();
    glDeleteProgram(skyboxShader);

========================================================================
CHANGES TO makefile
========================================================================

The Skybox.h header includes stb_image inline (STB_IMAGE_IMPLEMENTATION is
defined inside Skybox.h).  No extra .cpp is needed.

You DO need to download stb_image.h and place it next to your source files:
  https://raw.githubusercontent.com/nothings/stb/master/stb_image.h

No changes to SRCS are required — Skybox.h is header-only.

If you later split out a Skybox.cpp (to avoid the STB_IMAGE_IMPLEMENTATION
macro polluting headers), add Skybox.cpp to SRCS as normal.

Also add the two new shader files to your project directory:
  skyboxVert.glsl
  skyboxFrag.glsl
